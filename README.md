# 语安智库

面向多语种应急语言与国家安全研究的语料、学术与项目展示平台。

## 内容

- 20 个国家安全重点领域、2,854 条真实候选标注语料的检索、语境展示与来源溯源。
- 完整 JSONL 压缩包与 20 个领域子集的独立下载。
- 面向初学者的语料库、标注与语境科普。
- 应急语言服务相关学者、入门论文与项目入口。
- “语安智引”火灾逃生 AI 助手的公开版交互演示。

## 数据声明

仓库已收录 V3 版 20 个领域的 JSONL 候选标注数据，未收录体积较大的原始 Excel。全部记录均为 P0 候选敏感项、证据等级 C、置信度低，使用前需人工复核。详见 [数据卡](downloads/DATASET_CARD.md) 与 [公开发布说明](PROJECT_PUBLISHING_GUIDE.md)。

## 技术形式

不依赖框架或外部库的静态网站，可直接部署到 GitHub Pages。
